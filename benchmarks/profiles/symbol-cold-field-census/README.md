# Symbol cold-field census (diagnostic only)

Investigates a distinct Symbol storage layout: move Members, Exports and
ExportSymbol from every 96-byte Symbol to an optional typed record. A nominal
80-byte common record plus 24-byte optional record would save storage only if
sparsity offsets extra allocation, indirection and GC costs. No layout change
has been implemented or shown faster.

The isolated overlay samples construction ordinals 1,65,... separately for binder
and checker, capped at 262144 samples per origin. Samples use weak pointers and
are inspected after ordinary non-incremental compilation and two forced GCs while
the existing Program remains alive. A mutex protects only observer bookkeeping;
compiler Symbol fields are read after compilation work is complete. Concurrent
scheduling influences sample membership. Non-nil empty maps count as populated.
The eight masks describe Members, Exports and ExportSymbol independently.

Cleared samples and overflow remain explicit. This is not an unbiased population
estimate, peak occupancy, allocated-symbol count, all-symbol census, or proof of
semantic necessity. Symbols built outside the two instrumented constructors are
excluded. Temporary fields populated and later cleared are not observed. Weak
bookkeeping, locks and forced GC perturb execution; no observer timing belongs
in PERF.md. Disabled/enabled/baseline workload controls remain required.

Source review: checker cloneSymbol independently clones Members and Exports;
therefore copying a future cold-record pointer would not by itself preserve clone
semantics. Any migration must audit direct struct copies, literal construction,
field assignment, map aliasing, and stable published Symbol identity. Prior
rejected owned-symbol-links and compact SymbolTable layouts remain rejected.

Focused tests cover post-observation mutations, all eight masks including non-nil
empty maps, origin separation, stride/cap/cleared conservation, and concurrent
observer bookkeeping. They do not prove arbitrary concurrent Symbol mutation safe.
