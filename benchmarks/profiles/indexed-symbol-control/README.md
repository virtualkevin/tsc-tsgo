# Allocation-handle control for indexed symbol storage

This is variant 2 of the indexed-symbol pilot: immutable allocation handles on binder/checker symbols, with the original PointerLinkStore retained. The exact source change is ../indexed-symbol-pilot/handles.patch. The compiler is preserved locally as packages/tsc-go/dist/tsc-go-symbol-handles with a provenance sidecar. control-build.json records hashes, the exact five-file delta and matching build settings against the saturated-keybuilder baseline.

All five focused tests pass under normal, race and checkptr runs. Root units pass 2,341 records across ten packages without skips. The full pinned corpus has 12,789 fully checked and 8 partially checked cases, 2,118 unsupported skips, and no failures. Native parity passes 80 tests; actual-Go API, parallel emit and project integration passes 12, with no skips. Reports are in ../../validation/indexed-symbol-control-{conformance,native}.json. Focused and native logs are archived here; large root/conformance logs remain under /tmp/tsc-indexed-integration/control and their hashes are in the report. Validation timing is not workload performance evidence. No race-instrumented CLI run is claimed.

validate.py preserves the executed controller; it imports the committed prehashed-relations-512 validation helper solely for root/conformance log summarization. Its candidate-specific cache checks are not called. The controller requires an exact source hash and pinned corpus revisions; it checks source/HEAD between suites. native.py verifies binary/comparator/source identities and requires complete, unskipped suite counts. Both preserve their original absolute paths. Reruns require fresh output directories. The control-build.json validation field describes its state at build capture; the final reports above supersede that pending status.

layout-report.json reads concrete struct sizes from both executables using layout.go. Symbols grow96 to104 bytes, Binder288 to296, and Checker4752 to4760. SymbolAllocator is32 bytes. These are actual type sizes, not allocator size classes, total heap/RSS, or a speed result.

symbol_links_test.go.draft is an UNRUN wrapper-level test prepared for variant3. It covers checker-local domains, indexed/unindexed/nil keys, copied handles on distinct pointers, replacement, allocator reset, GC retention and preservation of lazy semantic IDs. It is not part of the validated control source. The indexed variant still needs compiler integration validation, race-instrumented CLI coverage, layout/codegen inspection, and three-way workload measurements plus A/A calibration. No candidate is promoted based on this control alone.
